# Пошаговая инструкция развертывания Home Assistant

> **Условные обозначения:**
> - 🏠 **ДОМА** — требует физического присутствия
> - 💻 **УДАЛЁННО** — можно сделать с работы (без прав администратора на рабочем ПК)
> - ⏱ — примерное время выполнения шага

---

## Предварительный план сессий

```
Сессия 1 (с работы, ~2-3 часа)
  └── Создание аккаунтов, скачивание файлов, подготовка

Сессия 2 (дома, ~3-4 часа)
  └── Физическая установка, сеть, запись USB, первый запуск HAOS

Сессия 3 (дома, ~2-3 часа)
  └── Базовая настройка HA, Zigbee, первые устройства

Сессия 4 (с работы или дома, ~3-4 часа)
  └── Все интеграции: Tuya, Яндекс, Алиса, автоматизации

Сессия 5 (дома, ~1-2 часа)
  └── Финальное тестирование, физическое сопряжение батарейных устройств
```

---

## СЕССИЯ 1 — Удалённая подготовка

> Всё это делается с браузера на рабочем компьютере. Установка программ не требуется.

---

### 💻 Шаг 1.1 — Скачать файлы на домашний компьютер заранее
⏱ 20 минут

Эти ссылки можно открыть дома заранее или отправить себе на почту/в Telegram.

**Файлы для скачивания (делать ДОМА перед сессией 2):**

| Файл | Адрес | Куда сохранить |
|------|-------|----------------|
| Home Assistant OS образ | github.com/home-assistant/operating-system/releases → `haos_generic-x86-64-XX.X.img.xz` | Рабочий стол |
| Balena Etcher (portable .exe) | etcher.balena.io → Download → Portable | Рабочий стол |
| AnyDesk Portable | anydesk.com → Download → Portable version (.exe) | Рабочий стол |

> **Почему AnyDesk Portable:** запускается без установки и без прав администратора — просто двойной клик по .exe. С рабочего компьютера тоже запускается без прав.

### 💻 Шаг 1.2 — Создать аккаунт Tuya Developer
⏱ 30 минут

Нужен для получения Local Key от WiFi Tuya/HOMMYN устройств.

1. Откройте **iot.tuya.com**
2. Нажмите **Sign Up** → Register with email
3. Заполните форму (можно использовать личный email)
4. После входа: **Cloud** → **Create Cloud Project**
   - Project Name: `HomeAssistant`
   - Industry: `Smart Home`
   - Development Method: `Smart Home`
   - Data Center: **Central Europe Data Center** (ближайший к России)
5. Нажмите **Create**
6. На следующем экране: выберите все API сервисы → **Authorize**
7. Перейдите: **Cloud** → **Devices** → **Link Tuya App Account**
8. Откройте приложение **Smart Life** на телефоне
9. Нажмите значок QR-кода в правом верхнем углу
10. Отсканируйте QR код на экране iot.tuya.com
11. Нажмите **Allow** в приложении

**Сохраните (запишите в безопасное место):**
- Access ID (Client ID): `__________________________`
- Access Secret: `__________________________`

> **Проверка:** После привязки перейдите Cloud → Devices — должны появиться все ваши устройства из Smart Life.

---

### 💻 Шаг 1.3 — Получить Local Key для каждого WiFi устройства
⏱ 30 минут

На сайте iot.tuya.com:

1. **Cloud → Devices → All Devices**
2. Для каждого устройства кликните на **Device ID** → откроется карточка
3. В карточке скопируйте:
   - `Device ID`
   - `IP Address` (может отсутствовать — узнаете позже из роутера)
   - Нажмите **Edit** → скопируйте `Local key`

**Таблица для заполнения (скопируйте в заметки):**

```
Устройство          | Device ID | Local Key | IP адрес
--------------------|-----------|-----------|----------
HOMMYN кондиц.      |           |           |
HOMMYN обогрев.     |           |           |
HOMMYN водонагрев.  |           |           |
Розетка WiFi 16A    |           |           |
Розетка WiFi 20A    |           |           |
Розетка WiFi Tuya   |           |           |
Лампочка с датчиком |           |           |
```

### 💻 Шаг 1.4 — Создать аккаунт Nabu Casa (внешний доступ к HA)
⏱ 10 минут

Нужен для голосового управления через Алису (Яндекс должен "достучаться" до вашего HA).

1. Откройте **account.nabucasa.com**
2. **Create Account** → заполните email и пароль
3. Выберите план: **$6.5/месяц** (есть месяц бесплатного пробного периода)
4. Оплатите (принимают карты, в том числе российские через определённые шлюзы)
5. Сохраните email и пароль — они понадобятся в HA

> **Альтернатива без оплаты:** Cloudflare Tunnel — бесплатно, но сложнее в настройке (описано в Сессии 4).

### 💻 Шаг 1.5 — Создать навык в Яндекс Диалогах (заготовка)
⏱ 20 минут

Навык нужен для связи Алисы с HA. Создаём заготовку сейчас, заполним URL позже.

1. Откройте **dialogs.yandex.ru**
2. Войдите через аккаунт Яндекса (тот же, что привязан к Станции Миди)
3. **Создать диалог** → **Умный дом**
4. Заполните:
   - Название: `Мой умный дом`
   - Backend endpoint: введите любой временный URL, например `https://example.com` (заменим позже)
5. **Сохранить черновик**
6. Запишите **Skill ID** из адресной строки или карточки навыка

**Сохраните:**
- Skill ID: `__________________________`
- Аккаунт Яндекса (email): `__________________________`

### 💻 Шаг 1.6 — Проверить прошивку SONOFF Dongle Max
⏱ 10 минут

Перед подключением важно убедиться что прошивка актуальна.

1. Откройте **itead.cc/sonoff-dongle-max** — найдите актуальную версию прошивки
2. Сравните с версией вашего устройства (написана на коробке или в приложении)
3. Если прошивка устарела — скачайте обновление и обновите ДОМА через web-интерфейс устройства

Зона: Ванная

  - Датчик воды ванная

Зона: Спальня

## СЕССИЯ 2 — Дома: физическая установка

> Требуется физическое присутствие. Время: 3–4 часа.

---

### 🏠 Шаг 2.1 — Закупить необходимое оборудование
⏱ Заранее

Если ещё не куплено:

| Компонент | Модель | Цена | Где купить |
|-----------|--------|------|-----------|
| PoE инжектор | TP-Link TL-POE150S | ~600 руб. | DNS, Ситилинк, Ozon |
| USB SSD или флешка | Samsung T7 (250GB) или USB флешка 32GB+ Class 10 | ~2500 / ~500 руб. | DNS, Ozon |
| Ethernet кабель Cat5e 2м | любой | ~100 руб. | любой магазин |
| Ethernet кабель Cat5e 1м | для Dongle Max | ~80 руб. | любой магазин |

> **Важно:** Не используйте встроенный HDD ноутбука для HA. Только внешний SSD или USB флешка.

---

### 🏠 Шаг 2.2 — Подключить сетевую инфраструктуру
⏱ 20 минут

```
1. Eltex RG-1520G-Wax LAN1 ──── [кабель Cat5e] ──── ASUS N551VW (LAN порт)
2. Eltex RG-1520G-Wax LAN2 ──── [кабель Cat5e] ──── TP-Link TL-POE150S (порт DATA IN)
3. TP-Link TL-POE150S (порт DATA+POWER OUT) ──── [кабель Cat5e] ──── SONOFF Dongle Max PoE (LAN порт)
4. TP-Link TL-POE150S подключить к питанию 220V
5. SONOFF Dongle Max подключить к питанию (или только через PoE — зависит от модели)
```

**Проверка:**
- Светодиод на Dongle Max горит → питание есть
- Войдите в веб-интерфейс роутера Eltex: **192.168.0.1** (или **192.168.1.1** — уточните на наклейке роутера)
- Найдите раздел: **DHCP** → **Clients** или **Список устройств**
- Убедитесь что Dongle Max получил IP-адрес (имя `SONOFF` или похожее)

---

### 🏠 Шаг 2.3 — Назначить статические IP через Eltex
⏱ 15 минут

В веб-интерфейсе роутера Eltex (192.168.0.1 или 192.168.1.1):

1. Войдите (логин/пароль на наклейке роутера или **admin / admin**)
2. Перейдите: **LAN** → **DHCP** → **Static IP** (или "Резервирование адресов")
3. Добавьте запись для ноутбука:
   - MAC-адрес: MAC LAN-порта ноутбука (в Windows: `ipconfig /all` в командной строке, поле "Physical Address" для Ethernet)
   - IP: `192.168.1.10`
4. Добавьте запись для SONOFF Dongle Max:
   - MAC-адрес: смотрите на наклейке устройства или в DHCP clients
   - IP: `192.168.1.11`
5. **Сохранить** → перезагрузите роутер если требуется

**Проверка:**
```
На ноутбуке откройте командную строку (Win+R → cmd):
ping 192.168.1.11
```
Должны быть ответы — Dongle Max доступен.

---

### 🏠 Шаг 2.4 — Проверить веб-интерфейс SONOFF Dongle Max
⏱ 10 минут

1. Откройте браузер на ноутбуке: **http://192.168.1.11**
2. Вы должны увидеть веб-интерфейс управления Dongle Max
3. Проверьте раздел с настройками сети — убедитесь что ser2net активен на порту **6638**
4. Запишите текущую версию прошивки (сравните с актуальной из Шага 1.6)

---

### 🏠 Шаг 2.5 — Записать образ Home Assistant OS на USB
⏱ 20 минут

На домашнем ноутбуке (не тот, на который ставим HA — нужен временно другой компьютер или телефон с OTG):

> Если другого компьютера нет: запись можно сделать с того же ноутбука, загрузившись с Live USB Linux. Но проще использовать второй ПК или попросить кого-то помочь.

1. Вставьте USB флешку или внешний SSD в компьютер
2. Запустите **Balena Etcher** (скачали в Шаге 1.1)
3. **Flash from file** → выберите `haos_generic-x86-64-XX.X.img.xz`
4. **Select target** → выберите вашу USB флешку/SSD
5. **Flash!** → ждите (~10 минут)
6. После завершения: Etcher покажет "Flash Complete"
7. Вытащите USB

> **Внимание:** Balena Etcher перезапишет всё содержимое USB носителя. Убедитесь что выбрали правильное устройство.

---

### 🏠 Шаг 2.6 — Настройка BIOS ноутбука ASUS N551VW
⏱ 10 минут

1. Вставьте USB с HAOS в ноутбук
2. Включите ноутбук, сразу нажимайте **F2** (возможно несколько раз)
3. В BIOS:
   - `Security` → `Secure Boot Control` → **Disabled**
   - `Boot` → `Boot Option #1` → выберите ваш USB носитель
   - `Advanced` → `USB Configuration` → `USB Legacy Support` → **Enabled**
4. Нажмите **F10** → Save and Exit → **Yes**

---

### 🏠 Шаг 2.7 — Первый запуск Home Assistant OS
⏱ 30 минут

1. Ноутбук загружается с USB — на экране побегут строки установки
2. Подождите 5–10 минут до появления:
   ```
   Home Assistant starting
   Visit http://homeassistant.local:8123
   ```
3. На любом другом устройстве (телефон) откройте **http://192.168.1.10:8123**
4. Запустится мастер первоначальной настройки:
   - Создайте аккаунт администратора (запишите логин и пароль!)
   - Укажите название дома, часовой пояс (Europe/Moscow)
   - Укажите ваш адрес (для прогноза погоды)
5. Пройдите все шаги мастера → нажмите **Finish**

**HA запущен!**

---

### 🏠 Шаг 2.8 — Установить AnyDesk на ноутбук с HA для удалённого управления
⏱ 10 минут

После запуска HA ноутбук работает как сервер. Нам нужно иметь возможность управлять самим ноутбуком удалённо (например, если HA завис или нужно что-то в BIOS).

1. HA работает в браузере — управлять им можно с любого устройства по IP
2. Но для управления **самим ноутбуком** (рабочий стол, терминал) нужен AnyDesk

**Вариант А — если HAOS установлен на USB и ноутбук можно использовать под Windows:**

Ноутбук будет работать под HAOS — нет рабочего стола Windows. В этом случае управление HA только через браузер по IP. AnyDesk на уровне HAOS не устанавливается.

**Вариант Б — SSH доступ к HAOS (рекомендуется):**

SSH позволяет управлять ноутбуком с HA из командной строки удалённо.

В HA:
1. `Settings` → `Add-ons` → `Add-on Store`
2. Найдите и установите: **Advanced SSH & Web Terminal**
3. В настройках add-on:
   ```yaml
   username: hassio
   password: "ВАШ_БЕЗОПАСНЫЙ_ПАРОЛЬ"
   ```
4. `Start` → `Show in sidebar`
5. Включите: `Network` → Port **22**

После этого с любого устройства (в том числе с работы):
```bash
ssh hassio@192.168.1.10
```

> Для доступа с РАБОТЫ (через интернет) SSH нужно проксировать через Nabu Casa или туннель — настроим в Сессии 4.

## СЕССИЯ 3 — Дома: базовая настройка Zigbee и первые устройства

> Требуется физическое присутствие для сопряжения устройств. Время: 2–3 часа.

---

### 🏠 Шаг 3.1 — Установить обязательные Add-ons
⏱ 20 минут

Откройте **http://192.168.1.10:8123** → Settings → Add-ons → Add-on Store

Устанавливайте в порядке:

**1. Mosquitto broker**
- Найдите в списке официальных add-ons
- Установить → Start → включить "Start on boot" и "Watchdog"

**2. File editor**
- Установить → Start → включить "Show in sidebar"

**3. Zigbee2MQTT**
- Найдите в add-on store (если нет — добавьте репозиторий: `https://github.com/zigbee2mqtt/hassio-zigbee2mqtt`)
- Установить → **не запускать пока**

---

### 🏠 Шаг 3.2 — Создать пользователя для MQTT
⏱ 5 минут

В add-on Mosquitto → Configuration:
```yaml
logins:
  - username: mqtt_user
    password: "ПРИДУМАЙТЕ_СЛОЖНЫЙ_ПАРОЛЬ"
customize:
  active: false
certfile: fullchain.pem
keyfile: privkey.pem
require_certificate: false
```
Сохраните → Restart Mosquitto.

---

### 🏠 Шаг 3.3 — Подключить MQTT интеграцию
⏱ 5 минут

`Settings` → `Devices & Services` → `Add Integration` → `MQTT`
- Broker: `core-mosquitto`
- Port: `1883`
- Username: `mqtt_user`
- Password: (из предыдущего шага)
- Нажмите Submit

---

### 🏠 Шаг 3.4 — Настроить Zigbee2MQTT
⏱ 15 минут

В File editor откройте: `/addon_configs/zigbee2mqtt/configuration.yaml`

Замените содержимое:
```yaml
mqtt:
  server: mqtt://core-mosquitto
  user: mqtt_user
  password: "ВАШ_MQTT_ПАРОЛЬ"

serial:
  port: tcp://192.168.1.11:6638
  adapter: ezsp

homeassistant:
  enabled: true

frontend:
  enabled: true
  port: 8099

advanced:
  log_level: info
  network_key: GENERATE
  pan_id: GENERATE
  channel: 25
```

Сохраните → Перейдите в add-on Zigbee2MQTT → **Start**

Проверьте логи — должно быть:
```
Zigbee2MQTT started!
Connected to MQTT server
```

---

### 🏠 Шаг 3.5 — Сопряжение Zigbee устройств
⏱ 60–90 минут

Откройте **http://192.168.1.10:8099** (Zigbee2MQTT Frontend)

**Порядок сопряжения (важен — сначала роутерные устройства):**

```
1. Нажмите [Permit join (All)] в Z2M Frontend

Группа А — Роутерные устройства (с питанием от сети):
  □ Модуль реле HOMMYN RLZBNN02 (2-кан.) — оба модуля
  □ Модуль реле HOMMYN RLZBNN01 (1-кан.)
  □ Розетка Zigbee Tuya 16A
  □ Умное реле Zigbee без нейтрали (Tuya)
  □ Реле Zigbee 1 линия
  □ Диммер ZM-105-M
  □ Выключатели проводные Zigbee 2-клавишные

Группа Б — Конечные устройства (батарейные):
  □ Датчик T/H Tuya Zigbee
  □ Датчик утечки воды Tuya Zigbee (все штуки)
  □ Датчик утечки воды Zigbee 3.0
  □ Беспроводные выключатели 2-клавишные Zigbee (×5)
  □ Беспроводная кнопка мультисцена

2. После появления каждого устройства: [Disable join]
3. Присвойте имя из вашего списка (Шаг 1.7)
```

**Как перевести устройство в режим сопряжения:**
- Реле HOMMYN: удерживайте кнопку сброса 5 секунд до мигания LED
- Розетки Tuya: удерживайте кнопку 5–10 секунд
- Датчики/кнопки: обычно 3 быстрых нажатия или зажать на 5 сек
- Если устройство не находится — сбросьте его к заводским настройкам

---

### 🏠 Шаг 3.6 — Проверить устройства в Home Assistant
⏱ 15 минут

1. `Settings` → `Devices & Services` → `MQTT`
2. Все Zigbee устройства должны появиться автоматически
3. Перейдите в `Overview` — нажмите на каждое устройство и проверьте что оно откликается
4. Для реле: нажмите переключатель → реле должно щёлкнуть

## СЕССИЯ 4 — Удалённо или дома: все интеграции

> После настройки внешнего доступа — всё остальное можно делать с работы через браузер.

---

### 🏠 Шаг 4.1 — Настроить внешний доступ (Nabu Casa)
⏱ 10 минут

*(Сначала сделайте ДОМА, затем управляйте удалённо)*

1. В HA: `Settings` → `Home Assistant Cloud`
2. Нажмите **Sign In** → введите данные аккаунта Nabu Casa (создали в Шаге 1.4)
3. Дождитесь надписи: `You are connected to the Nabu Casa cloud`
4. В разделе **Remote Access**: нажмите **Enable**
5. Скопируйте ваш URL вида: `https://XXXX.ui.nabu.casa`

**Проверка с телефона (не в домашней WiFi сети):**
Откройте `https://XXXX.ui.nabu.casa` → должна открыться ваша HA.

**Теперь HA доступен из интернета — можно работать удалённо!**

---

### 💻 Шаг 4.2 — Установить HACS (менеджер кастомных интеграций)
⏱ 15 минут

*Делать с браузера по адресу `https://XXXX.ui.nabu.casa`*

1. В HA: `Settings` → `Add-ons` → `Advanced SSH & Web Terminal` → **Open Web UI**
2. В терминале введите:
   ```bash
   wget -O - https://get.hacs.xyz | bash -
   ```
3. После завершения: `Settings` → **Developer Tools** → **Restart**
4. После перезапуска: `Settings` → `Devices & Services` → `Add Integration` → `HACS`
5. Следуйте инструкциям: нужен GitHub аккаунт (создайте бесплатно на github.com если нет)
6. HACS появится в левом меню

### 💻 Шаг 4.3 — Установить LocalTuya
⏱ 10 минут

1. HACS → **Integrations** → поиск `localtuya`
2. Установить → **Reload**
3. `Settings` → `Devices & Services` → `Add Integration` → `LocalTuya`

Для каждого WiFi устройства (из таблицы Шага 1.3):
- **Host:** IP устройства (найдите в роутере Eltex → DHCP Clients, или задайте статический)
- **Device ID:** из Tuya Developer
- **Local Key:** из Tuya Developer
- Выберите тип устройства из списка

> **Совет:** Сначала назначьте статические IP всем Tuya устройствам через роутер Eltex.

### 💻 Шаг 4.4 — Установить Yandex Smart Home (YSH)
⏱ 20 минут

1. HACS → **Integrations** → поиск `yandex smart home`
2. Установить → **Reload**
3. `Settings` → `Devices & Services` → `Add Integration` → `Yandex Smart Home`

В настройках выберите: **Connection via Nabu Casa cloud** (самый простой вариант):
- Это автоматически использует ваш Nabu Casa URL
- Никаких дополнительных настроек не нужно

### 💻 Шаг 4.5 — Привязать навык Яндекса к HA
⏱ 15 минут

1. Откройте **dialogs.yandex.ru** → ваш черновик навыка (из Шага 1.5)
2. В поле Backend endpoint замените на:
   ```
   https://XXXX.ui.nabu.casa/api/yandex_smart_home/v1.0
   ```
   (ваш Nabu Casa URL + `/api/yandex_smart_home/v1.0`)
3. Сохраните → **На модерацию** (для приватного использования — достаточно черновика)

4. В приложении **Яндекс** на телефоне:
   - Устройства → Добавить → Умный дом → найдите ваш навык
   - Нажмите **Привязать аккаунт**
   - Войдите в аккаунт HA через открывшееся окно
   - Все устройства из HA синхронизируются в Яндекс

### 💻 Шаг 4.6 — Задать русские имена устройствам в HA
⏱ 20 минут

*Это критично для голосового управления Алисой*

Для каждого устройства в HA:
1. `Settings` → `Devices & Services` → нажмите на устройство
2. Нажмите на entity (сущность)
3. Нажмите на иконку редактирования
4. В поле **Name** введите русское имя из вашего плана (Шаг 1.7)
5. Сохраните

После переименования — скажите Алисе: "Алиса, обнови устройства умного дома"

### 💻 Шаг 4.7 — Добавить камеру Cootli
⏱ 10 минут

В HA: `Settings` → `Devices & Services` → `Add Integration` → `Generic Camera`

```yaml
# Если Generic Camera не спрашивает YAML, используйте configuration.yaml:
camera:
  - platform: generic
    name: "Камера уличная"
    still_image_url: "http://192.168.X.XX/snapshot.jpg"
    stream_source: "rtsp://admin:ПАРОЛЬ@192.168.X.XX:554/stream1"
    verify_ssl: false
```

IP камеры найдите в роутере Eltex → DHCP Clients (имя начинается с `Cootli` или `IPC`).

Пароль от камеры: стандартный `admin` или из приложения Cootli.

### 💻 Шаг 4.8 — Настроить автоматизацию для посудомойки
⏱ 10 минут

*Если посудомойка подключена через умную розетку с мониторингом мощности*

`Settings` → `Automations` → `Create Automation` → `Edit in YAML`:

```yaml
alias: "Посудомойка закончила работу"
trigger:
  - platform: numeric_state
    entity_id: sensor.НАЗВАНИЕ_РОЗЕТКИ_power
    below: 5
    for: "00:05:00"
condition:
  - condition: template
    value_template: "{{ states('sensor.НАЗВАНИЕ_РОЗЕТКИ_power') | float > 0.5 }}"
action:
  - service: media_player.play_media
    target:
      entity_id: media_player.yandex_station_midi
    data:
      media_content_id: "Посудомоечная машина закончила работу"
      media_content_type: "text"
```

## Удалённое управление HA с работы

После выполнения Шага 4.1 (Nabu Casa) — доступ с работы через браузер:

| Что делать | Как | Нужна ли установка |
|-----------|-----|-------------------|
| Управлять устройствами | `https://XXXX.ui.nabu.casa` в браузере | ❌ Ничего не нужно |
| Редактировать конфиги | HA → File Editor (в браузере) | ❌ Ничего не нужно |
| Смотреть логи | HA → Settings → System → Logs | ❌ Ничего не нужно |
| SSH доступ | Web Terminal в HA (в браузере) | ❌ Ничего не нужно |
| Устанавливать add-ons | HA → Add-ons (в браузере) | ❌ Ничего не нужно |
| Смотреть камеру | HA → Overview → Camera card | ❌ Ничего не нужно |
| Запустить AnyDesk с работы | `anydesk.exe` portable (без установки) | ⚠️ Только portable .exe |

> **Вывод:** После настройки Nabu Casa всё управление HA ведётся через обычный браузер. На рабочем компьютере ничего устанавливать не нужно.

| Проблема | Первый шаг диагностики |
|---------|----------------------|
| HA недоступен локально | `ping 192.168.1.10` → перезагрузить ноутбук |
